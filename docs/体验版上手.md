# 云扫墓 · 体验版上手（AppID wxf04af40a1e8481b9）

目标：在自己和亲友的手机微信里打开云扫墓，试用 3D 墓园、摇杆走动、献花上香、留言、邀请。

## 一、拿到代码
1. 打开 https://github.com/harbor0816at-design/yunsaomu → 绿色「Code」→「Download ZIP」，解压到电脑任意位置。
   （会用 git 的话：`git clone https://github.com/harbor0816at-design/yunsaomu.git`）
2. 安装「微信开发者工具」稳定版：https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html

## 二、导入项目
1. 打开开发者工具，用**小程序管理员或开发者**的微信扫码登录。
2. 「导入项目」→ 目录选解压后的 `yunsaomu` 文件夹 → AppID 会自动显示 `wxf04af40a1e8481b9` → 后端服务选「不使用云服务」→ 确定。
3. 右上角「详情 → 本地设置」：确认勾选「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」。
4. 模拟器里应能看到首页，点「进入示例纪念墓」或新建一座墓。

## 三、先用「预览」在自己手机上看（最快）
1. 工具栏点「预览」→ 用手机微信扫二维码。
2. 进入后点右上角「…」→「开发调试」→ 打开，小程序会重启。
   **必须打开**：后端目前是 Supabase 域名，没有 ICP 备案，不能填进「服务器域名」，只有开发调试模式下才放行。

## 四、上传为体验版（给亲友试）
1. 工具栏点「上传」→ 版本号填 `0.1.0`，备注「MVP 体验」→ 上传。
2. 打开 https://mp.weixin.qq.com →「管理 → 版本管理」→ 开发版本里找到 0.1.0 →「选为体验版」，会出一个体验二维码。
3. 「管理 → 成员管理 → 体验成员」→ 添加亲友微信号（个人主体最多 15 人，企业更多）。
4. 亲友扫体验二维码进入，同样要在「…」里打开「开发调试」。

## 五、后台还要顺手填的
- 「设置 → 服务内容声明 → 用户隐私保护指引」：勾选**剪贴板**（读取：粘贴邀请链接；写入：复制管理链接、邀请链接）。不填的话，首页「粘贴邀请链接」在体验版里会失败。

## 六、试用时请记录
- 手机型号 / 系统，3D 墓园是否流畅（卡的话右上「景」里可切流畅画质）
- 左下摇杆的位置和手感、鞠躬动作、擦碑
- 两台手机同进一座墓，能否看到对方走动和献花

## 正式上线还差什么
见 `docs/发布清单.md`：服务类目、小程序备案、备案域名 + 后端迁国内、内容安全、正式隐私政策。体验版不受这些限制。
