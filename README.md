# 云扫墓 · 微信小程序

想念的时候，来看看。

PRD v0.2（V2.0）第 1 阶段的微信小程序客户端：首页三入口、两屏建墓、沉浸式祭奠场景（四季 / 昼夜 / 天气）、五种祭奠动作、碑面滑动擦拭、留言与建墓人审核、微信好友分享、多人实时同步。

后端复用现有 Supabase Edge Function `api`（与网页版同一套接口与令牌，线上 55 座旧墓的邀请 / 管理链接都能直接进入）。

## 视觉规范

画面质感参考山寺（sansatemple.com）：

- **3D 墓园**（`scene3d/memorial3d.js`）：three.js r108 低多边形、平直着色的立体小院。包含远山、雾、石板路、中式门楼（朱红立柱、灰瓦顶）、两级石台和矮石栏、三式碑（碑面为刻字加灰尘的动态贴图，可滑动擦拭）、供桌香炉、烛火光、花束、四季枫树和松、石灯笼（夜里亮）、落叶 / 飘雪 / 萤火 / 细雨。墓前有一段铺石甬道（两侧路沿、成对石灯笼、入口望柱），可站 16 人。自己是第三人称小人：轻点地面走过去（迈腿摆臂、平滑转身、到达后面向墓碑），镜头平滑跟随，拖动围着自己环视，双指缩放；鞠躬为「转向墓碑 → 合掌 → 弯腰约 45° → 停留 → 起身」三次后放手。亲友从入口走进来站到空位，各自位置经实时频道同步（只广播坐标）。预览：`docs/motion-preview.png`。全部为程序化原创几何体，不加载外部模型。
- **回退**：WebGL 不可用时自动退回 2D 画面（`scene/engine.js`），接口一致。
- **界面**：深橄榄底 `#24251f`、半透明深色面板、奶油色文字 `#fffdf3`、金色选中 `#e6d5ad`、橄榄实心按钮 `#747353`、主行动按钮为金色。首页头图和分享封面由 `test/render-hero.js` 用自家 3D 场景渲染。
- **小程序依赖**：`libs/threejs-miniprogram.js`（微信官方 threejs-miniprogram 0.0.8 的构建产物，MIT，内含 three.js r108），不需要再 npm 构建。主包约 1.1MB。
- 预览：`docs/ui-preview.png`、`docs/scene-preview.png`。

| `test/` | 单测（模拟 `wx` 跑页面流程）与 headless Chrome 场景截图 |

## 本地运行

1. 用微信开发者工具「导入项目」选择本目录。没有 AppID 时可用测试号（`touristappid`）。
2. 详情 → 本地设置 → 勾选 **「不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书」**。开发期直连 `*.supabase.co`，正式版必须换成已备案域名，见 `docs/发布清单.md`。
3. 基础库 ≥ 2.16（Canvas 2D）。真机预览同样需要在调试模式下打开。

## 测试

```bash
node --test test/unit.test.js        # 校验、链接解析、季节昼夜、短提示、建墓与祭奠页面流程
node test/render-scenes.js out/      # 2D 回退画面截图
node test/render-3d.js out3d/        # 3D 墓园截图（headless Chrome + WebGL），核对碑面命中
node test/render-hero.js             # 重新生成首页头图与分享封面
```

## 已知差异（相对网页版）

- 3D 场景可环视、缩放，但不能像网页版那样自由行走；访客站位固定在路两旁。
- 小程序端与网页端访客在同一座墓时，祭奠动作、擦碑、留言互相可见；在场人数与剪影只统计小程序端。
- 第 1 阶段小程序不支持上传照片（需要接入微信图片内容安全，后续阶段做）。
